# road100

[在线使用](https://mrglll.github.io/road100/)

将道路百米指标拆分为十米数据，支持多个 Excel 批量处理、结果校验及 ZIP 下载。文件在浏览器本机处理，不上传源表。

## 访问与使用统计

使用 GoatCounter 匿名统计，管理者登录 [统计后台](https://mrggllll.goatcounter.com/) 查看。

- 网页访问路径：`/road100/`。
- `road100-batch-success`：成功完成批处理。
- `road100-export-zip`：生成批处理ZIP下载。
- `road100-batch-failed`：本批无成功结果或处理失败。

事件仅在相应操作成功时计数（失败事件单列），不是点击选择文件就算成功使用。访问与事件分开查看，Totals合计包含功能事件，不能直接当作访客人数。初始数据包含发布验收测试。匿名访客是估计值，可能受网络和广告拦截器影响。

统计不发送文件内容、文件名、表格数据、模型属性、输入内容或错误原文；不发送页面地址参数和来源信息。本地打开或开发预览不发送统计。统计异常不影响原有功能。统计客户端内嵌，许可见`THIRD_PARTY_NOTICES.txt`，不包含账号密码或API密钥。
